# Quantum Quiz

An AI-powered quiz application covering 10 quantum computing subjects. Each question is
generated on-demand by Claude (`claude-sonnet-4-6`) with optional Qiskit context (circuit
diagrams, statevectors, Hamiltonians) embedded in the prompt. Open-ended answers are graded
by Claude with per-point feedback and a model answer.

---

## Features

- **10 subjects, 114 topics** — from linear algebra through quantum algorithm design
- **4 question types** — conceptual explanation, calculation, circuit design, proof sketch
- **3 difficulty levels** — beginner, intermediate, advanced (or randomised per question)
- **Qiskit-enriched prompts** — relevant subjects automatically receive rendered circuit
  images, statevector printouts, or Hamiltonian strings to ground questions in real code
- **Hint system** — up to 3 progressive hints per question, generated by Claude
- **Spaced repetition weighting** — past session scores influence which subjects appear most
- **Deduplication window** — the last 8 question texts are shown to Claude to prevent repeats
- **Session history** — sortable table of all past sessions with per-subject score breakdown
- **Collapsible panels** — model answer and key-points-missed are hidden by default and
  animated open on click
- **Score bar** — animated 0–10 progress bar colour-coded by verdict

## Usage

### Setup Screen

1. **Select subjects** — all 10 are checked by default; deselect any you want to skip
2. **Pick difficulty** — Beginner / Intermediate / Advanced / Mixed
3. **Pick question types** — any combination of the four types
4. **Set question count** — default 10
5. Click **Start Quiz**

The total topic pool is shown as you adjust selections. All-none combinations are
rejected with a warning.

### Question Screen

- The question is displayed in a card. For Qiskit-relevant topics a circuit image or
  statevector may appear alongside the question text.
- Type your answer in the free-text box.
- Click **Hint** (up to 3 times) to reveal progressive hints.
- Click **Skip** to advance without answering (does not count toward score).
- Click **Submit Answer** to send to Claude for grading.

A loading overlay appears while Claude grades. On error, a dialog offers a retry or
skip option.

### Feedback Screen

- **Score bar** animates to your score (0–10)
- **Verdict badge** — Correct (≥7) / Partially correct (≥4) / Incorrect (<4)
- **Feedback** — Claude's prose explanation
- **Model answer** — collapsible panel, click to expand
- **Key points missed** — collapsible panel (only shown when verdict is not Correct)
- **Follow-up question** — suggested next topic
- Click **Next Question** or wait for the session to end

### Summary Screen

- Overall average score and per-subject breakdown as a bar chart (matplotlib)
- **Drill again** to re-run the same configuration
- **Back to Setup** to reconfigure

### History Screen

- Table of all past sessions: date, subjects, question count, average score
- Click any row to expand the per-question detail
- **Clear history** button (with confirmation)

## Configuration (`config.py`)

| Constant | Default | Effect |
|---|---|---|
| `CLAUDE_MODEL` | `claude-sonnet-4-6` | Model used for generation and evaluation |
| `GENERATION_MAX_TOKENS` | 900 | Max tokens for question generation response |
| `EVALUATION_MAX_TOKENS` | 1300 | Max tokens for grading response |
| `DEFAULT_QUESTION_COUNT` | 10 | Pre-filled question count on setup screen |
| `MAX_HINT_COUNT` | 3 | Maximum hints displayed per question |
| `PREVIOUS_QUESTION_DEDUP_WINDOW` | 8 | Number of recent question texts sent to Claude |
| `SCORE_CORRECT_THRESHOLD` | 7 | Score ≥ this → "Correct" verdict |
| `SCORE_PARTIAL_THRESHOLD` | 4 | Score ≥ this → "Partially correct" verdict |
| `CIRCUIT_RENDER_DPI` | 120 | DPI for Qiskit circuit PNG rendering |
| `CIRCUIT_MAX_QUBITS` | 6 | Maximum qubit count in rendered circuits |

## Grading Rubric

Scores 0–10 are returned by Claude. The verdict mapping is:

| Score | Verdict |
|---|---|
| 7–10 | Correct |
| 4–6 | Partially correct |
| 0–3 | Incorrect |

Claude is prompted to return a JSON object with `score`, `feedback`, `model_answer`,
`key_points_missed` (list), and `follow_up` fields.

---

## Data Persistence

Sessions are appended to `~/.local/share/quantum-study/quantum_quiz_history.json` as a
JSON array. Each entry records: timestamp, subjects, difficulty, question count, average
score, and per-question records (subject, topic, question text, user answer, score,
feedback, model answer).

The SRS weight calculation reads this file on session start. Weights are computed using
an exponential decay factor of 0.88 per session back in time: subjects where you scored
poorly recently receive proportionally more questions.
